How it plays

Everyone starts with the same stack of virtual PulseVR cash. Each round a mystery box hits the block — bid in $50 increments. Win the bid, pay the price, and the box opens live: it could be Cash App money, a Meta Quest app, VRChat Plus, PulseVR membership perks… or a BUST (nothing, −$50, or −$100). Hit $0 and you're out. One round per game is a sealed High Roller round — one secret bid each. Everyone gets one Peek per game: learn whether a box is a prize or a bust.

Players join from their phone with a 4-letter room code. The host screen runs the show; the broadcast view is built to be streamed into VRChat.
